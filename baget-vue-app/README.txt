ДРУК ТА ЕКСПОРТ ЗВІТІВ

Архів містить лише змінені та нові файли. Накладіть backend/src на src бекенду,
frontend/src — на src Vue-проєкту. Перезапустіть бекенд і перебудуйте фронтенд.
Міграцій БД і нових залежностей немає. Потрібні попередні три звіти власника.

У звітах власних філій, посередників та руху грошей додано:
- Друк / PDF: окреме вікно з кнопкою друку; PDF через діалог браузера.
- Excel: справжній .xlsx, числові суми, заголовки, фільтри, підсумки.
- Усі рядки за застосованим періодом/фільтрами, не лише поточна сторінка.
- Дата формування, пояснення неповних сум. Звіт формується заново на момент експорту.
- Доступ лише адміністратору; ліміт 10000 рядків, період до 366 днів.

Виправлено оборот власних філій після об’єднання частково сплачених рахунків:
вартість береться з первісного рахунку, не з перенесеного залишку боргу.
Неоднозначні або відсутні первісні рахунки дають невизначену суму.
Борг посередника залишається поточним, без обмеження періодом/філією.

Перевірено тут:
- Синтаксис 428 Java-файлів (не повна перевірка типів).
- Компіляція Java OOXML writer і читання XLSX через openpyxl: числа,
  літеральні формули, Unicode, заголовки, фільтри, невизначені значення.
- 20 попередніх перевірок Vue-звітів та перевірка експорту/екранування.
- ESLint чотирьох Vue-компонентів.
- SQL власних філій на тестових SQLite-даних: подвійне об’єднання,
  повторна видача, доопрацювання до/після видачі, коригування винагород,
  невідомі ціни, скасовані й неоднозначні первісні рахунки.
Це не інтеграційний тест MySQL. Повний Gradle тут не запускався.

У вашому середовищі:
.\gradlew.bat test --tests "com.example.baget.reports.*"

Перевірте друк у вашому браузері та Excel/LibreOffice. Для друку дозвольте
відкриття нового вікна. На телефоні доступність PDF залежить від браузера.
Рекомендований контроль: рахунок 1000 грн, оплата 400 грн, об’єднання залишку
600 грн — оборот виробу має залишатися 1000 грн.
