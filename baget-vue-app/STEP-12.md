# Крок 12 — Vue-калькулятор оформлення

У «Нове замовлення» є вкладки «Розрахунок» (початкова) та «Оформлення замовлення» (попередня форма). Перемикання вкладок зберігає введені дані в пам’яті; вихід із розділу або перезавантаження сторінки очищає їх.

Реалізовано FRAMED_ARTWORK: до 50 незалежних виробів, розміри роботи в мм, рама з чинного каталогу, кілька матеріалів кожної групи, кількість шарів на виріб, чотири поля паспарту, AUTO/MANUAL/NONE, кількість підвісів і лапок. Тип 2 паспарту має нейтральну назву за наданим переліком. Поля додаються один раз для шару з найменшим отвором. Інші отвори та примітки не передаються, оскільки preview API їх не зберігає.

POST /api/calculations/estimate-preview використовує чинний VITE_API_URL та Bearer-токен. Ціни, витрати, кріплення, термосклейку, шнур, округлення й підсумки повертає backend. Фронтенд не підставляє резервних цін. Сумісність підвісів перевіряє сервер; помилки показуються з номером виробу, якщо він є у відповіді.

Кошторис показує загальні витрати й суми для всієї кількості виробів у позиції. Після редагування старий результат прибирається, запит скасовується, запізнілі відповіді ігноруються. Розрахунок виконується кнопкою. Без паспарту приховані поля не передаються; приховані ручні параметри кріплень теж не передаються.

Попередня форма оформлення не змінена, її старі локальні формули не замінено. Новий кошторис не переноситься в неї автоматично. Збереження складу, приміток і результату в Orders/Items — окремий крок 13. Підрамники, натяжка, доставка й інші старі опції не включені до нового калькулятора оформлення; їх не можна вважати врахованими в його сумі.

## Встановлення

Архів містить вихідний проєкт без .git, node_modules і dist. Скопіюйте файли поверх своєї копії зі збереженням структури. Не видаляйте локальну папку .git, .env чи node_modules.
Змінено src/App.vue; додано src/components/EstimateCalculator.vue, src/calculation/estimate.js, src/services/calculations.js, tests/estimate.test.mjs та цей опис. Залежності не змінено.

У каталозі baget-vue-app:

```powershell
node --test tests/estimate.test.mjs
npm run lint
npm run build
npm run dev
```

Для чистого встановлення спочатку npm ci. Backend повинен містити крок 11 і налаштовані матеріали.

## Перевірка в середовищі розробки

- 5 тестів формування запиту пройшли: шари/геометрія, приховані поля, ручні підвіси, некоректні значення, окремі вироби.
- ESLint усього проєкту: без помилок.
- Vue SFC-компіляція App.vue та EstimateCalculator.vue: без помилок.
- Повна Vite-збірка не завершилась: надані залежності для Windows не містять @rollup/rollup-linux-x64-gnu, необхідного в цьому Linux-середовищі.
- Браузерну перевірку не виконано: у середовищі відсутній виконуваний Chromium. Візуальний вигляд та взаємодія з реальною БД не перевірені.

Після запуску перевірте: звичайну раму, два матеріали скла, ПВХ, кілька шарів паспарту з різними полями; ручні та автоматичні підвіси; два вироби в кошторисі; зміну поля після розрахунку; помилку сервера. Старий підсумок має зникати після зміни параметрів.
